# Proceso MVT en la App

## Objetivo

Documentar validación real de una propuesta de negocio con trazabilidad y evidencia.

## Paso 1: Inmersión (entrevistas)

Requisito mínimo:
- 5 conversaciones reales.

Campos:
- contacto anonimizado
- canal (`whatsapp|llamada|presencial|otro`)
- fecha
- resumen
- problema actual
- solución actual
- intensidad del dolor
- disposición a pagar
- evidencia (link o archivo)

## Paso 2: Hipótesis

Requisito mínimo:
- 5 supuestos listados.
- ranking por riesgo.
- 2–3 críticos.

## Paso 3: Test

Tipos:
- landing
- smoke test
- preventa
- post
- demo/Figma

Campos:
- test_type
- descripción
- métrica definida antes de ejecutar
- valor objetivo
- evidencia (URL/captura/archivo)

## Paso 4: Análisis

Campos:
- métrica objetivo
- métrica real
- conclusión (`validada|invalidada|inconclusa`)
- análisis honesto

## Paso 5: Decisión

Opciones:
- avanzar
- pivotear
- re-testear
- descartar

Campos:
- razonamiento
- siguiente paso concreto

## Criterios de evidencia evaluable

- Todo registro con timestamp.
- Evidencias accesibles desde UI.
- Unión clara: propuesta -> validación -> entrevistas/tests/resultados.
- No permitir “completar” MVT sin mínimos obligatorios.
